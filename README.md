# Glucose Intelligence — хмарна версія (Supabase + GitHub Pages)

## Крок 1 — База даних (один раз)
1. Зайди в свій проєкт на supabase.com → **SQL Editor** → **New query**
2. Встав увесь вміст файлу `schema.sql`, натисни **Run**
3. Перевір: **Authentication → Providers** — Email має бути увімкнений (за замовчуванням так)
4. Якщо не хочеш підтверджувати email при кожній тестовій реєстрації:
   **Authentication → Settings → Email Auth** → вимкни "Confirm email"

## Крок 2 — Розмістити на GitHub Pages
1. Створи новий репозиторій на GitHub (публічний або приватний — Pages працює з обома на платних акаунтах, з безкоштовним лише публічний)
2. Заливаєш ВСІ файли з цієї папки, зберігаючи структуру:
   ```
   index.html
   patient.html
   doctor.html
   css/style.css
   js/glucose-core.js
   js/render.js
   js/supabase-client.js
   js/auth.js
   js/patient-app.js
   js/doctor-app.js
   ```
3. **Settings → Pages** → Source: `main` branch, `/ (root)` → Save
4. За хвилину-дві сайт буде доступний за адресою `https://твій-акаунт.github.io/назва-репозиторію/`

## Крок 3 — Перевірка
1. Відкрий сайт → зареєструйся як **Пацієнт** (своя пошта)
2. Завантаж CSV-файл сенсора кнопкою вгорі — має з'явитися дашборд
3. Відкрий сайт **в іншому браузері або приватному вікні** → зареєструйся як **Лікар** (інша пошта)
4. Поверніся в акаунт пацієнта → розділ "Мої лікарі" → введи email лікаря → "Надати доступ"
5. Онови сторінку лікаря — пацієнт має з'явитись у списку, клік відкриває його дашборд (тільки перегляд)

## Що важливо знати
- Дані про глюкозу зберігаються на серверах Supabase, не лише локально
- Захист — на рівні бази даних (Row Level Security), а не в коді сторінки: навіть підмінивши запит у браузері, лікар фізично не отримає дані пацієнта, який не надавав доступу
- anon-ключ у коді — публічний за задумом Supabase, це нормально й безпечно
- Я не мав мережевого доступу до supabase.co під час розробки — усю логіку перевірив локально через симуляцію відповідей бази, але саме з'єднання з ТВОЇМ проєктом перевіриш тільки ти в браузері. Якщо щось піде не так при першому вході — напиши точний текст помилки, розберемось.
